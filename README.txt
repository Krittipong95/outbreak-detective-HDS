นักสืบโรคระบาด ๒ : ปริศนาแห่งบ้านสุขใจ
=========================================

วิธีเปิดเกม
  ดับเบิลคลิก index.html (ใช้ Chrome หรือ Edge) — ไม่ต้องติดตั้งอะไร
  ถ้าไม่มีอินเทอร์เน็ต เกมยังเล่นได้ แต่ฟอนต์ไทยแบบลายไทย (Srisakdi/Charm) จะใช้ฟอนต์ของเครื่องแทน

โครงเรื่อง (ประมาณ ๓๐–๔๕ นาที)
  บทนำ      เสียงโทรศัพท์ยามดึก
  บทที่ ๑    ระบาดจริงหรือแค่ฤดูกาล?  (ค่ามัธยฐาน ๕ ปี, นิยามผู้ป่วย)
  บทที่ ๒    ข้อมูลไม่เคยสะอาด        (ข้อมูลซ้ำ, ปี พ.ศ./ค.ศ., ค่าผิดปกติ, ผู้ไม่เข้านิยาม)
  บทที่ ๓    ลงพื้นที่                (case-control, Odds Ratio, Mantel–Haenszel, ตรวจสิ่งแวดล้อม, แล็บ, ห่วงโซ่อุปทาน)
  บทที่ ๔    กระดานสืบสวน → รายงานสอบสวนโรค + ตอนจบ (มีหลายตอนจบตามผลงาน)
  ปุ่ม "ลงพื้นที่ทันที" ที่หน้าแรก = ข้ามไปบทที่ ๓ (เหมาะกับบูธที่มีเวลาน้อย)

ต้นตอสุ่มได้ ๖ รูปแบบ: บ่อน้ำ · ร้านอาหาร · โรงน้ำแข็ง (ซ่อน) · สวนผัก (ซ่อน) · โรงเรียน · งานเลี้ยง
  คำตอบไม่ตายตัว — เชื้อสุ่มตามความน่าจะเป็นของแต่ละแหล่ง การแพร่คนสู่คนและรูปแบบการระบาดเกิดจากการระบาดจริง
  โรงเรียนมี ๓ แบบ (แม่ครัวป่วย · อาหารเก็บผิดอุณหภูมิ · แท็งก์น้ำดื่ม) งานเลี้ยงมี ๓ เมนูที่อาจเป็นต้นตอ
  คดีหักมุม: ร้านอาหารที่เป็น "ตัวแปรกวน" มี OR สูงแต่ไม่ใช่ต้นตอ (ต้องแยกวิเคราะห์ตามหมู่บ้าน)

ใหม่ในเวอร์ชัน ๓: 🚶 เดินสำรวจหมู่บ้าน (บทที่ ๓ · ปุ่มสีทองเหนือแผนที่)
  หมู่บ้านพิกเซลอาร์ตมุมบน วาดด้วยโค้ดทั้งหมด (js/walk.js · css/walk.css) ไม่มีไฟล์ภาพ ใช้พิกัดเดียวกับแผนที่ข้อมูล
  เดิน: ปุ่มลูกศร / WASD หรือแตะ/คลิกที่พื้น (หาทางอ้อมสิ่งกีดขวางและข้ามสะพานเอง) · แตะแผนที่ย่อเพื่อเดินทางไกล · 🔍 ซูม
  คุย/สำรวจ: กด E / Space หรือแตะปุ่ม 💬 เมื่อมีเครื่องหมาย ! ขึ้น
    🏥 รพ.สต. = ฐานทีม HDS (พี่วิให้คำแนะนำ + ปุ่มสัมภาษณ์ ตั้งสมมติฐาน กลุ่มควบคุม ข้ามเวลา เขียนรายงาน)
    สถานที่ ๑๒ แห่ง = ตรวจสิ่งแวดล้อม · เก็บตัวอย่างส่งแล็บ · สั่งปิด · ดูสัดส่วนผู้ป่วยที่เคยสัมผัส · กระโดดไปไฮไลต์บนแผนที่ข้อมูล
    ลานหมู่บ้าน ๕ แห่ง = อัตราป่วยต่อประชากร ๑,๐๐๐ คน เทียบทุกหมู่ · 🚩 ธงแดง = บ้านผู้ป่วย (แผนที่จุดแบบจอห์น สโนว์)
    ชาวบ้าน กำนัน ป้าบุญมา หลวงพ่อ แม่ค้า ผอ. คุยได้ (คำพูดเปลี่ยนตามความเชื่อมั่นชุมชนและสถานการณ์)
  ✨ การ์ดความรู้ ๑๐ ใบซ่อนอยู่ในหมู่บ้าน · ฟ้ามืดตามเวลาในเกม (เย็น/กลางคืนมีไฟตามบ้าน หิ่งห้อยริมคลอง)
  🏃 Shift = วิ่ง · แตะค้างแล้วลาก = บังคับทิศแบบจอยสติ๊ก · 🧭 ไปที่… = เลือกสถานที่แล้วเดินไปเองตามลูกศรสีทอง
  🚲 ยืมจักรยานที่ รพ.สต. — เร็วขึ้นเกือบ ๒ เท่า (กด B ขึ้น/ลง)
  📌 ภารกิจชาวบ้าน ๓ อย่าง (ความเชื่อมั่นชุมชน +๒ ต่อภารกิจ):
     🐔 ตามหาไก่นางดำของยายผิน · 🧼 สอนน้องล้างมือ ๗ ขั้นตอน (มินิเกม) · 🗑️ เก็บขยะริมคลองให้ลุงเผือก
  📒 สมุดนักสำรวจ: เหรียญ ๙ เหรียญ · สถานะภารกิจ · อ่านการ์ดความรู้ที่เก็บได้ซ้ำ
  เวลาเดินทางมีค่า: เดิน ๔ กม. หรือปั่น ๑๒ กม. = ๑ ชม. ในเกม (คิดเมื่อทำภารกิจหรือกลับหน้าข้อมูล)

ระบบที่ทำให้เล่นสนุกขึ้น
  🎙️ สัมภาษณ์เชิงลึก — คุยกับผู้ป่วยรายแรก/รายที่นอนโรงพยาบาล ขอความยินยอมก่อน แล้วเลือกคำถาม ๓ ข้อ
                       คำถามปลายเปิดได้เบาะแสจริง คำถามชี้นำได้คำตอบที่เอนเอียง
  📌 กระดานสืบสวน — ก่อนเขียนรายงาน โยงการ์ดหลักฐานกับผู้ต้องสงสัยด้วยด้ายแดง
                    ผู้ต้องสงสัยที่มีหลักฐานครบ ๓ ด้าน (สถิติ · สิ่งแวดล้อม · แล็บ) คือข้อสรุปที่หนักแน่น
  ❤️ ความสนิทกับกำนัน ป้าบุญมา พี่ฟ้า — ตั้งแต่ ๗๐ ได้ความช่วยเหลือพิเศษ (เก็บกลุ่มควบคุมเร็วขึ้น ·
                    ค้นหาเชิงรุกฟรี · ผลแล็บเร็วขึ้น) ต่ำกว่า ๒๕ งานจะยากขึ้น
  ☀️ รายงานเช้า — สรุปผู้ป่วยรายใหม่ แนวโน้ม และเวลาที่เหลือทุกเช้า
  🏆 สถิติและเหรียญ — ตารางคะแนน (วันนี้/ตลอดกาล) · เหรียญ ๒๐ เหรียญ · แฟ้มคดีต้นตอที่เคยไขได้
  📅 คดีประจำวัน — ทุกคนในวันเดียวกันเล่นคดีเดียวกัน (ระดับนักวิทยาศาสตร์ข้อมูล · ลงพื้นที่ทันที) แข่งอันดับในเครื่อง
  ระดับ S ต้องได้ ๘๘๐ คะแนนขึ้นไป และไม่มีการตัดสินใจที่ผิด (❌) ในเหตุการณ์ใดเลย
  ▶ อัตโนมัติ — ปุ่มบนฉากเล่าเรื่อง เลื่อนข้อความเองตามความยาว (⏩ เร่ง ยังใช้ได้เหมือนเดิม)
  🔊 เสียงเอฟเฟกต์ (โทรศัพท์ ผลแล็บ ประทับตรา ได้เหรียญ) — เปิด/ปิดพร้อมเพลงด้วยปุ่ม 🎵
  สถิติและเหรียญเก็บในเครื่องนี้เท่านั้น ล้างได้จากปุ่ม "ล้างสถิติทั้งหมด" ในหน้าสถิติ

เครื่องมือวิทยาศาสตร์ข้อมูลสุขภาพ (HDS) — เขียนเองทั้งหมด รันในเบราว์เซอร์ ไม่มีค่าใช้จ่าย เล่นออฟไลน์ได้
  🚨 ระบบเตือนภัยอัตโนมัติ (บทที่ ๑ ข้อ ๔) — ตั้งค่า ค่ามัธยฐานย้อนหลัง / EARS C2 / CUSUM กับข้อมูล ๓ ปีที่มีเฉลย
                        ให้จับการระบาดได้ครบโดยเตือนผิดไม่เกินเป้า เห็นการแลกเปลี่ยนความไวกับการเตือนผิด (alarm fatigue)
  🤖 แท็บ ML (บทที่ ๓ ข้างตาราง OR)
       📉 Logistic regression หลายตัวแปร — เลือกตัวแปรเอง ปรับตามหมู่บ้าน/อายุ ได้ OR ที่ปรับแล้ว + 95% CI + AUC แบบ cross-validation
          ปักผลเป็นหลักฐาน “สถิติ” บนกระดานสืบสวนได้ (คดีตัวแปรกวน: OR ของร้านจะลดลงเมื่อปรับหมู่บ้าน)
       🌳 Decision tree — ปรับความลึก เห็นกราฟ overfitting (ข้อมูลฝึก vs 5-fold CV) feature importance และต้นไม้แบบอ่านได้
       💻 ข้อมูล · โค้ด · SQL — ดาวน์โหลด CSV (ใช้รหัสแทนชื่อ) · Jupyter Notebook (pandas/statsmodels/scikit-learn) · R script
          และ SQL console (ตาราง linelist, survey) — SQL ใช้ alasql ที่โหลดจากอินเทอร์เน็ตครั้งแรกที่กดรัน
  🧭 วิเคราะห์เชิงพื้นที่บนแผนที่ — DBSCAN จับกลุ่มผู้ป่วย · แผนที่ความร้อน (KDE) · อัตราป่วยต่อประชากร
  📱 ฟังเสียงโซเชียล (NLP) — ติดป้ายโพสต์ ๙ โพสต์ → ฝึก Naive Bayes (ตัดคำภาษาไทยด้วย Intl.Segmenter) → ทายชุดทดสอบ
                        → ดึงชื่อสถานที่ เทียบ “กระแสรวมยอดแชร์” กับ “เฉพาะโพสต์ที่เล่าอาการจริง”
  🤖 ผู้ช่วย AI ของจังหวัด (เหตุการณ์ใหม่) — AI มั่นใจเกินจริง ดูแค่สัดส่วนผู้ป่วย และแต่งแหล่งอ้างอิง
                        ฝึกอ่าน model card · ขอคำอธิบาย (XAI) · เทียบกับ case-control · จับ hallucination
  🔮 พยากรณ์ในรายงานเช้า — เลือกโมเดล (naive / ค่าเฉลี่ย ๓ วัน / แนวโน้มเอ็กซ์โพเนนเชียล) แล้ววันรุ่งขึ้นดูค่าคลาดเคลื่อน (MAE)
  📘 คู่มือเพิ่ม ๗ บท: ระบบเฝ้าระวังอัตโนมัติ · ML · NLP · ข้อมูลเชิงพื้นที่ · การพยากรณ์ · AI อย่างรับผิดชอบ · เครื่องมือ (SQL/Python/R/ICD-10)
  🎖️ เหรียญใหม่ ๘ เหรียญ · หน้าผลลัพธ์แสดงทักษะ HDS ที่ใช้ในคดี และสรุป “เครื่องมือ HDS” ที่ยังไม่ได้ลอง

ตัวละครของคุณ
  เลือกเป็น ชาย หรือ หญิง ได้ที่หน้าแรก (คำลงท้าย ครับ/ค่ะ เปลี่ยนตาม)
  ภาพของคุณจะขึ้นข้างกล่องข้อความเวลาพูด บนแถบสถานะภาคสนาม และในหน้าผลลัพธ์

เหตุการณ์ระหว่างสอบสวน (ทุกการตัดสินใจมีผลต่อเนื่อง · เล่นซ้ำแล้วไม่เหมือนเดิม)
  ทุกคดีมีเหตุการณ์หลัก แต่สุ่มรูปแบบทุกครั้ง:
    ข่าวลือ        — สถานที่ที่โดนลือสุ่มทุกคดี และ ๒๐% ข่าวลือก็ถูกจริง (ต้องดูข้อมูลเสมอ)
    แรงกดดันให้ปิด — ประชาคมที่ศาลา / ชาวบ้านประท้วงหน้า รพ.สต. / กำนันไลฟ์สดเฟซบุ๊ก
    ผู้ป่วยขาดน้ำ    — ยายทองใบ (๘๒ ปี) / น้องใบบัว (ขวบแปดเดือน) / ตาบุญส่ง (เบาหวาน)
    งานวันเสาร์     — งานทอดกฐินที่วัด / งานแต่งลูกสาวกำนัน
    สื่อ            — วิทยุชุมชน / ทีวีถ่ายทอดสด / เพจดังไลฟ์
    และ พี่ฟ้าขอใบนำส่งตัวอย่าง (ครั้งแรกที่ส่งแล็บ)
  ขึ้นกับสิ่งที่คุณทำ: ชาวบ้านเล่าเบาะแส (ถ้าชี้แจงประชาคม) หรือข่าวลืองอกใหม่ (ถ้าไม่ชี้แจง)
                      · อสม. ป่วย (ถ้าไม่ได้เตรียมอุปกรณ์ป้องกันตัว) · เจ้าของร้านที่ถูกปิดมาร้องเรียน
                      · ฉลากตัวอย่างเลอะ (ถ้าไม่กรอกใบนำส่ง) · ผลต่อเนื่องของผู้ป่วยขาดน้ำ งานวันเสาร์ และการประกาศของนายอำเภอ
  สุ่ม ๓ ใน ๗ ต่อคดี (เวลาเกิดสุ่มด้วย): รายชื่อผู้ป่วยหลุด (PDPA) · พายุฝนเข้า · นายอำเภอขอให้ประกาศว่าคลี่คลาย
                      · น้ำสมุนไพรวิเศษขายทางไลฟ์ · ผอ. ขอปิดโรงเรียน · ตำบลข้างเคียงพบผู้ป่วย · นักศึกษาอาสา
  📜 หน้าสถิติมี "เหตุการณ์ที่เคยเจอ" ให้สะสม และมีเหรียญเมื่อเจอเหตุการณ์สุ่มครบทุกแบบ
  ❓ บนแผนที่ = โรงน้ำแข็ง/สวนผักที่ยังไม่รู้จัก — ค้นพบได้จากการตรวจร้านอาหาร หรือ 📦 ห่วงโซ่อุปทาน
  ผลที่เกิดขึ้นจริงในเกม เช่น งานกฐินที่จัดโดยไม่มีมาตรการทำให้เกิดผู้ป่วยระลอกใหม่ · การยอมเปิดแหล่งโรคคืนทำให้เชื้อกลับมาแพร่
  · การตีตราผู้ป่วยหรือทีมที่ป่วยทำให้ชาวบ้านตอบแบบสอบถามคลาดเคลื่อน · ความเชื่อมั่นชุมชนขึ้นลงตามการตัดสินใจ

ท้ายเกม
  "เรื่องราวหลังจากนั้น" — ผลของการตัดสินใจแต่ละครั้งต่อชาวบ้านและตำบล
  "สรุปว่าคุณพลาดอะไรบ้าง" — ๖ ด้าน: รายงาน · การเก็บหลักฐาน · ๑๐ ขั้นตอน · การตัดสินใจในเหตุการณ์ · ข้อมูลบทที่ ๑–๒ · เวลาและผลกระทบ
  พร้อมไทม์ไลน์การตัดสินใจทั้งหมด และสิ่งที่ทำได้ดี

ตัวช่วยในเกม
  📘 คู่มือนักสืบมือใหม่ (ปุ่มมุมล่างซ้าย / หน้าแรก) — ๑๒ บท ตั้งแต่ ๑๐ ขั้นตอนการสอบสวน ถึงการดูแลผู้ป่วยขาดน้ำ
  ✅ เช็คลิสต์ — ความคืบหน้า ๑๐ ขั้นตอน และสิ่งที่ต้องรู้ให้ได้ก่อนเขียนรายงาน
  ⏭️ ข้ามเวลา — รอ ๑๒ ชม. / ข้ามไปจนผลแล็บออก / ข้ามไปเช้าวันถัดไป
